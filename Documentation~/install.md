# Install Unity OpenXR: Meta

Unity OpenXR: Meta is an official Unity package available from the [Package Manager](xref:um-upm-ui). To understand how to install a package via the Package Manager, refer to [Install a UPM package from a registry](xref:um-upm-ui-install).

## Dependencies

To use Unity OpenXR: Meta 2.6, your project must meet the following requirements:

* Unity 6 (6000.0 or newer)
* [Android Build Support](xref:um-android-install-dependencies) module
* AR Foundation 6.6.0-pre.2 or newer
* OpenXR Plug-in 1.17.0 or newer
* XR Composition Layers 2.4.0 or newer

The Package Manager automatically installs required package dependencies if you don't already have them installed.
